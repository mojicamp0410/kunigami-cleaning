# 国頭村森林公園 清掃管理システム

宿泊施設の清掃状況をスタッフ全員でリアルタイム共有するWebアプリです。
スマートフォンのブラウザから利用します。

**アプリURL** → https://mojicamp0410.github.io/kunigami-cleaning/

---

## できること

- 全9棟の清掃進捗を1画面で把握
- 工程ごとのチェック（誰が・いつチェックしたかを記録）
- 引き継ぎメモの共有（記入者・記入日時つき）
- コテージの洗濯物状況の表示
- 次回チェックイン日の登録
- 毎日10:00に自動リセット
- 作業ログのスプレッドシート記録

## 使い方

### 1. 担当者を選ぶ

画面上部で自分の名前を選択します。端末ごとに記憶されるので、初回だけで大丈夫です。
**選択しないとチェックできません。**

### 2. 清掃を記録する

清掃の進め方に応じて2通りあります。

| 方法 | 操作 | 記録のされ方 |
|---|---|---|
| **工程チェック** | 各工程をタップ | `✅ 使用可`（緑）＋誰がいつチェックしたか |
| **一括完了** | 「📋 一括完了」ボタン | `📋 一括完了`（黄）※個別工程は記録されない |

新人研修や手順の確認には工程チェック、慣れたスタッフの日常業務には一括完了、という使い分けを想定しています。

### 3. 引き継ぎメモ

忘れ物・破損・備品の残量などを記入します。記入者と日時が自動で残ります。
リセットされても消えないので、翌日の担当者にも伝わります。

---

## 自動リセットについて

毎日 **10:00（日本時間）** に全施設が自動でリセットされます。

| リセットされる | 保持される |
|---|---|
| 工程チェック / 担当者 / 完了ステータス / 洗濯物 | 引き継ぎメモ / 次回チェックイン日 |

10:00以降に初めてアプリを開いた場合も、その時点でリセットが実行されます。

## 表示がおかしいと感じたら

### まず ⟳ ボタンを押す

画面右上の **⟳** を押すと、未保存の変更を保存してから最新版を取得します。
「他の人と表示が違う」の多くはこれで解決します。

### それでも直らない場合

右上の **🩺** を押すと診断情報が出ます。
**表示が違う2台の端末で押して見比べてください。**

| 項目 | 見るポイント |
|---|---|
| アプリ版数 | 2台で違う → 古い方で ⟳ を押す |
| 最終同期 | 何分も前 → 通信状況を確認 |
| 直近エラー | 内容が出ている → 管理者に共有 |
| 未送信ログ | 溜まり続ける → 通信状況を確認 |

## 管理者向け

### 構成

```
GitHub Pages (index.html)  ←  スタッフのスマホからアクセス
        ↕ 同期
Google Apps Script         ←  バックエンド
        ↕
Googleスプレッドシート      ←  状態の保存 ＋ 作業ログの蓄積
```

サーバーは不要です。データはすべてGoogleスプレッドシート上にあります。

### ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで完結） |
| `kunigami_gas_backend.gs` | GAS側のコード（Apps Scriptに貼り付けて使用） |
| `セットアップ手順_v5.md` | 更新手順とトラブル対応 |

### 更新するときの注意

**HTMLを更新したら `APP_VERSION` を必ず上げてください。**

```javascript
const APP_VERSION = "5.0.0";  // ← ここを上げる
```

これを忘れると、診断画面で端末間のバージョン差が検出できなくなります。

**工程を増やしたときはGAS側の再デプロイは不要**ですが、GASのコードを変更した場合は
「デプロイを管理」→ 鉛筆アイコン →「新バージョン」→ デプロイ が必要です。
「新しいデプロイ」を選ぶとURLが変わってしまうので注意してください。

### 更新後は全スタッフに再読み込みを依頼

スマートフォンのブラウザは古いHTMLをキャッシュし続けます。
更新後は各自に **⟳ ボタン** を押してもらってください。

### スプレッドシートの集計

スプレッドシート上部の **「📊 清掃管理」メニュー** から実行します。

| シート | 内容 |
|---|---|
| `activity_log` | 全操作のログ（1行＝1操作） |
| `daily_summary` | 日付×担当者の作業量 |
| `staff_monthly` | 月別の稼働日数・作業量 |
| `_state` | システム用（編集しないこと） |

作業量スコアは `工程チェック×1 + 一括完了×8 + メモ記入×2` で算出しています。
ただし工程数の多いコテージ担当は数値が高く出やすく、清掃の丁寧さや仕上がりの質は
数字に表れません。**参考値**として扱ってください。

## 技術メモ

- 単一HTMLファイル（ビルド不要・依存パッケージなし）
- 通信不能時はlocalStorageに保存し、復帰時に自動送信
- 保存はPOST送信（GETのURL長制限を回避）
- 施設ごとの更新時刻を比較してマージ（同時編集による上書きを防止）
- 保存失敗時は3回まで自動リトライ
- 日付判定は日本時間固定（端末のタイムゾーン設定に依存しない）
